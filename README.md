# 마루온 (Maruon)

서울·인천·경기·부산은 **동·읍까지**, 대전·대구·울산과 지정 시·군은 **시군구까지** 쪽을 둔
출장마사지·홈타이 방문 안내 정적 사이트. 의존성 0, Node 표준 라이브러리만 쓴다.

```
npm run regions   # /tmp/hjd.geojson → data/regions.json  (행정동 경계 → 실측값)
npm run build     # → dist/
npm run check     # 14종 게이트
npm run simil     # 동·읍 쪽끼리 본문 겹침 비율
npm run serve     # 로컬 확인 (http://127.0.0.1:8080)
```

## 쪽 구성 (1,587쪽)

| 층 | 주소 | 수 |
|---|---|---|
| 대문 | `/` | 1 |
| 받는 자리 허브 | `/area/` | 1 |
| 시도 | `/{시도}/` | 15 |
| 시군구 | `/{시도}/{시군구}/` | 152 |
| **동·읍** | `/{시도}/{시군구}/{동}/` | **1,275** |
| 코스 | `/course/{코스}/` | 8 |
| 시도 × 코스 | `/{시도}/course/{코스}/` | 120 |
| 코스 허브·금액·이용안내·소개·약관·개인정보 | | 6 |
| 노트 | `/magazine/` + 글 7 | 8 |
| 404 | `/404.html` (noindex·사이트맵 제외) | 1 |

### 일부러 만들지 않은 조합
- **동·읍 × 코스** — 1,275 × 8 = 10,200쪽. 자리가 달라져도 코스 설명이 같아 전부 얇은 조합 페이지가 된다.
- **면(面) 쪽** — 354곳. 집이 흩어져 있어 한 쪽을 채울 고유 사실이 안 나온다. 시군구 쪽에 이름만 적는다(접수는 받는다).
- **서브 지역의 동 쪽** — 깊이를 두 층으로 갈랐다. 동 이름은 시군구 쪽 목록에 있다.
- **옹진군·군위군** — 섬과 산골뿐이라 방문이 성립하지 않는다. 아예 싣지 않았다.

## 지역 데이터

`scripts/build-regions.mjs` 가 공개 행정동 경계(admdongkor `HangJeongDong_ver20260701`, CC BY 4.0)에서
아래 값을 **계산해서** 뽑는다. 손으로 적어 넣은 숫자가 없다.

- 동·읍 : 면적가중 중심점 좌표 · 넓이 · **가로/세로 폭**(경계를 감싸는 네모) · **경계를 맞댄 행정동**
- 시군구 : 중심점 · 넓이 · 행정동 수 · 면 목록 · **맞닿은 시군구**
- 시도 : 중심점 · 넓이 · 시군구 수 · 행정동 수

### ★맞닿음 판정
두 행정동이 경계 좌표(소수점 6자리)를 **2개 이상** 나눠 가지면 맞닿은 것으로 본다.
1개면 모서리에서 점으로 스친 것이라 뺀다.
**중심점 사이 거리로 '가까운 동'을 뽑지 않는다** — 강 건너가 1등으로 올라오기 때문이다.

실측 규모: 시도 15(동·읍까지 4) · 시군구 152 · 동 1,232 + 읍 43 = 1,275 · 면 354 · 맞닿은 쌍 3,458.

## 지키는 일곱 가지

1. **같은 주소 = 같은 HTML.** 무작위를 쓰지 않는다. 문장 고르기는 전부 주소 기반 해시다. 두 번 빌드해 `dist` 해시가 같은지 본다.
2. **전화번호는 `telBtn()` 으로만 찍는다.** 안심번호 옆에 '예약 문의'가 늘 붙는다. 검사도구 11번이 세 갈래로 본다.
3. **후기·체험담·평점·인물 사진을 싣지 않는다.** `aggregateRating` 도 넣지 않는다.
4. **푸터에 AI 활용 고지**를 둔다.
5. **lastmod 는 본문 해시로 판정한다**(`data/lastmod.json`). ★이 파일은 **반드시 커밋**한다. 없이 깃에서 빌드하면 전 쪽이 매번 '오늘 수정'으로 밀려 거짓 신선도 신호가 된다.
6. **robots.txt 는 Yeti·Yeti-Mobile·`*` 세 그룹에 같은 규칙**을 적는다(Yeti 그룹을 두면 `*` 를 통째로 무시한다). `Crawl-delay` 는 적지 않는다.
7. **뒷받침 못 하는 단정을 쓰지 않는다.** 맞닿은 이웃이 없는 자리에는 '한 번에 이어 돈다'를 쓰지 않고, 커버리지 밖 이웃도 숫자에서 빼지 않는다.

## 색인

- 사이트맵 색인 + 조각(`core` + 시도 15) + `sitemap-latest.xml`(최근 14일 · 최대 2,000)
- `rss.xml` — `lastBuildDate` 는 **글 발행일**로 둔다(빌드 시각을 쓰면 같은 내용에도 파일이 매번 달라진다)
- `llms.txt` — 사실 요약과 자료 출처
- IndexNow 키 파일은 `data/site.config.json` 의 `indexNowKey` 로 루트에 떨어진다. **키는 사이트마다 달라야 한다.**

## 호스팅 — Cloudflare

`dist/_headers` 와 `dist/_redirects` 를 빌드가 함께 떨어뜨린다. Cloudflare Pages·Workers 정적 자산 모두 그대로 읽는다.

| | |
|---|---|
| 빌드 명령 | `node src/build.mjs` |
| 출력 폴더 | `dist` |
| Node | 20 |
| Workers Builds | `wrangler.jsonc` 참고 (main 없는 자산 전용 워커) |

기준 주소는 **`https://maruon-care.yovip77.workers.dev`**(Cloudflare Workers 정적 자산, 2026-10-12 배포).
★Pages 가 아니라 Workers 라 `*.pages.dev` 가 아니고 `*.<계정>.workers.dev` 다.
정식 도메인을 붙이면 `data/site.config.json` 의 `siteUrl` 을 그 주소로 바꾸고 **다시 빌드**한다 —
canonical·사이트맵·RSS·llms.txt 가 전부 그 값을 쓴다.
